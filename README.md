## 🌟 Executive Overview

**MULTIGALAXIAL LIFE** is an interdisciplinary scientific research platform that bridges observational astrophysics, high-performance computer vision, spacecraft flight software architecture, and sensor-driven artificial life simulation.

The platform is developed in two coordinated, production-ready stages:

1. **LEVEL 1 — NASA TRL 7 Computer Vision Engine & Deep Galaxy Morphometry:**
   - 100-Level Scientific Computer Vision Hierarchy spanning 10 core astronomical domains.
   - Dual-branch AstroNet architecture combining deep convolutional representation learning with classical non-parametric Concentration-Asymmetry-Smoothness (CAS) morphometry.
   - NASA TRL 7 Mission Control Center featuring real-time CCSDS 133.0-B-2 Space Packet Protocol decoding, autonomous Fault Detection, Isolation, and Recovery (FDIR), SPICE ephemeris kinematics, and formal NPR 7150.2 Software Engineering verification.
   - 1,010 passing automated unit and integration tests (`experiments/exp_01_galaxy_morphology/tests/`).
   - 16 verified Level 1 Research Volumes (640 pages) in `volumes/` and `docx_sources/`.

2. **LEVEL 2 — Sensor-Driven Artificial Life and Interactive 3D Ecosystem Simulation:**
   - Closed-loop sensorimotor simulation of hypothetical organisms on procedurally synthesized planetary terrains.
   - Articulated multi-segment morphology generation with analytical 2-bone Inverse Kinematics (IK) and terrain-conforming tripod gaits.
   - Multi-modal simulated sensor suite: multi-ray LiDAR proximity rangefinders, olfactory chemotaxis sniffers, virtual pinhole RGB/depth cameras, and IMUs.
   - Virtual RISC-32 Microprocessor simulation with cycle-accurate instruction accounting, scheduling latency, dynamic clock throttling (50 Hz – 25 kHz), and computational power dissipation.
   - Deterministic Finite State Machine (FSM) and closed-loop heading PID feedback controllers.
   - Interactive 3D WebGL ecosystem studio supporting Chase, Orbit, and First-Person camera perspectives with real-time sensor ray and nutrient field visualizations.
   - 14 mandatory Level 2 Acceptance Tests passing cleanly (`level_2/tests_level_2.py`).
   - 40 new Level 2 Research Volumes (1,600 main-body pages, exactly 40 pages per volume validated via PyPDF) across 8 Parts in `level_2/volumes/` and `level_2/docx_sources/`.

## 🔬 Epistemological Demarcation

In accordance with strict scientific epistemology, all elements within Multigalaxial Life are categorized under four explicit ontological tiers:

- **Category A (Observed Ground Truth):** Established terrestrial biochemistry and peer-reviewed astronomical catalogs (e.g., SDSS DR16).
- **Category B (Laboratory Synthetic Biology):** In vitro artificial life, protocell chemistry, and laboratory robotics.
- **Category C (Astrobiological Hypotheses):** Theoretical habitable zone models, speculative prebiotic pathways, and spectroscopic biosignature proposals.
- **Category D (Synthetic Simulation Constructs):** All Level 2 hypothetical organisms, alien biomes, and virtual microprocessors are computational software models. *They do NOT constitute assertions of discovered extraterrestrial life or physical semiconductor benchmarks.*

## 🚀 Quickstart & Interactive Dashboard

### 1. Installation

```bash
git clone https://github.com/ananya39836-blip/multigalaxial_life.git
cd multigalaxial_life
pip install -r requirements.txt
```

### 2. Launch Streamlit Scientific Control Center

```bash
cd experiments/exp_01_galaxy_morphology
streamlit run cv_dashboard.py
```

Access the dashboard at `http://localhost:8501` (or forwarded ports). The dashboard features:
- **Tab 1: 🚀 NASA TRL 7 Mission Control:** Real-time CCSDS telemetry decoding, autonomous FDIR failover, and verification matrix.
- **Tab 2: 🎮 3D Movable LiDAR & Flight Studio:** 3D spacecraft polar orbit swath, planetary landing hazard mapping, and visual-inertial SLAM.
- **Tab 3: 🧬 Level 2: Artificial Life 3D Studio:** Real-time 3D WebGL ecosystem simulation, live organism spawner, virtual CPU clock throttling, and empirical Landmark Experiment 01 analytics.
- **Tabs 4–8:** Galaxy observation browser, dual-branch deep vision diagnostics, structured anomaly evidence system, 100-level CV hierarchy, and quantitative benchmark reports.
